# Board Resources

Add bundled chessboard resources here. Files under `App/` are included in the app bundle.

Expected piece image paths use this pattern for each theme:

- `App/Resources/Pieces/Rhosgfx/rhosgfx_wK.png`
- `App/Resources/Pieces/Staunton/staunton_wK.png`
- `App/Resources/Pieces/Fantasy/fantasy_wK.png`
- `App/Resources/Pieces/Spatial/spatial_wK.png`
- `App/Resources/Pieces/Celtic/celtic_wK.png`
- `App/Resources/Pieces/Sashite/sashite_wK.png`

Each theme includes `wK`, `wQ`, `wR`, `wB`, `wN`, `wP`, `bK`, `bQ`, `bR`, `bB`, `bN`, and `bP`.

Expected sound paths:

- `App/Resources/Sounds/move.mp3`
- `App/Resources/Sounds/capture.mp3`
- `App/Resources/Sounds/check.mp3`

The board falls back to Unicode chess symbols when piece image files are missing.
